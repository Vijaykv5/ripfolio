## Palette — Polar Cyan

**Vibe:** clean · kinetic · digital  
**Category:** consumer crypto / collectibles  
**Mood:** bold · premium

The full semantic token set is applied to `app/globals.css` as a light-first product theme. The pre-brand stylesheet is preserved at `app/globals.css.bak`.

Core tokens:

```css
--background: oklch(0.985 0.008 205);
--foreground: oklch(0.19 0.035 220);
--primary: oklch(0.5 0.2 250);
--primary-foreground: oklch(0.99 0 0);
```

All foreground/background, button-label, focus-ring, and muted-text pairs are intended to meet WCAG AA. Re-check contrast whenever token lightness changes.

## Typography — Sora

- **Display + body:** Sora, self-hosted as a variable TTF via `next/font/local`
- **Numbers + addresses:** Sora with tabular numerals
- **License:** SIL Open Font License 1.1 at `app/fonts/Sora-OFL.txt`

Use Sora’s semibold weight for headings and controls, regular for body text, and tabular numerals for prices and addresses.

## Gradients

Two restrained gradients are defined as `--gradient-bg` and `--gradient-accent`.

- Use the background gradient only for the pack stage or similarly large brand moments.
- Reserve the accent gradient for a future campaign treatment; primary transaction buttons stay solid for clear contrast.
- Never stack both gradients in the same component.

## Tone and voice

Use direct, specific, number-forward language with a little collectible energy. Describe what happens on-chain in plain terms. Prefer “3 cards, verified on Solana” over abstract claims.

Avoid “revolutionary,” “seamless,” “exclusive,” artificial urgency, and unexplained crypto jargon. Never imply that a wallet action occurred before it is confirmed.

> Three asset-backed cards. One verifiable reveal.

## Usage dos and don'ts

**Do:**

- Use semantic CSS tokens for every product color.
- Use the 4 px spacing grid and comfortable mobile touch targets.
- Keep blue as the single non-semantic accent.
- Use Sora with `tabular-nums` for financial values.
- Respect reduced-motion settings.

**Don't:**

- Reintroduce neon green or lime.
- Use pure black in the product UI.
- Use `transition: all`.
- Place body text over the accent gradient.
- Invent a second decorative accent color.
